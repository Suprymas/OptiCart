# Product Image URLs Template

# Format: product_name|image_url

#

# Instructions:

# 1. Visit https://barbora.lt or https://www.rimi.lt on your browser

# 2. Search for each product

# 3. Right-click on the product image and select "Copy image link"

# 4. Replace the placeholder URL below with the actual store image URL

# 5. Save this file as: product_images.txt

# 6. Run: python manage.py update_product_images --file product_images.txt

#

# Example:

# Pienas DVARO 2,5% 1 l|https://barbora-cdn.lt/image-123456.jpg
